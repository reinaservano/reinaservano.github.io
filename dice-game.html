Dice Game

Description

One-Hot Encoded Dice Game

FPGA • Digital Logic Design

  • Designed and programmed an FPGA-based dice game of rolling 22, utilizing clocked and clock-enabled Flip-Flops.
  • Built a custom binary-to-hexadecimal display decoder for readable game output.
  • Created an original score tracker-comparator and game turn counter to manage gameplay logic.
